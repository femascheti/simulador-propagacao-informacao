Como a informação se espalha?

Este tutorial guiado explica como uma informação se espalha por uma rede de pessoas conectadas, através de uma simulação interativa.

Por trás desta rede tem um grafo: uma rede de pontos (as pessoas) ligados por linhas (as conexões entre elas). É assim que os cientistas de dados representam qualquer rede, seja de amigos, de contatos ou de informações que se espalham.

Comece por aqui!

Para iniciar, clique no nó laranja, ele tem uma informação guardada. Você pode escolher repassar ou não repassar a informação.

Você repassou a informação! Agora observe o caminho que ela percorre pela rede.

Você não repassou a informação. Ninguém mais vai ver ela.

Antes de seguir, relembre o que cada cor significa: azul é quem ainda não viu a informação, rosa é quem viu mas ainda não decidiu, laranja é quem está selecionado agora, verde é quem repassou, e bege é quem recebeu e decidiu não repassar. Clique em "Próximo nível" de novo pra continuar.
